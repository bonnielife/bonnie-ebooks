隱私權政策（Bonnie Ebook Reply）

更新日期：2026 年 11 月 20 日

「Bonnie Ebook Reply」是邦妮讀書筆記自用的小工具，只用在 Bonnie 自己的 YouTube 頻道：當網友在影片下方留言提到「電子書」時，自動回覆電子書下載連結。

會讀取哪些資料

只讀取 Bonnie 自己頻道底下的公開留言內容，用來判斷是否提到「電子書」。

會做什麼

只會在符合條件的留言下方，以 Bonnie 的頻道身分回覆一則下載連結。不會刪除、修改任何影片或留言。

資料保存與分享

只在 Bonnie 自己的電腦上保存「已回覆過的留言編號」，避免重複回覆。不收集、不出售、不分享任何網友個人資料給第三方。

使用 Google API 的說明

本工具透過 YouTube Data API 運作，使用方式遵守 Google API 服務使用者資料政策，包括有限使用規定。
